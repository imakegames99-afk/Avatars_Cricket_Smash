About This Website

This website is the official platform for the game Avatrs Cricket Smash. It allows players to create their own custom 3D face avatars and download them for use inside the game.

Users can design their unique identity and bring it into gameplay, making the experience more personal and immersive.

All avatars are optimized for performance and fully compatible with the Avatrs Cricket Smash game engine.

This website is fast, secure, and does not require user accounts. It is designed to provide a simple and smooth experience for all players.

Avatrs Cricket Smash and this website are independently developed and maintained as part of a creative game development project.
